# SaaS Observability Agent

Adopt the profile in `../../agents/observability-cost-agent.md` and follow `../../core/workflows/agent-execution.md`.

Start from operational decisions, then define the minimum useful signals, thresholds, ownership, and response. Separate application, dependency, job, database, AI, storage, and cost evidence. Do not collect unnecessary personal data or mutate monitoring history without approval.
