# Data and Database Role

## Outcome

Protect data integrity, authorization, migration safety, and query performance throughout the product lifecycle.

## Responsibilities

- Model relational constraints and lifecycle states.
- Design forward-safe migrations and controlled backfills.
- Enforce tenant and row-level authorization.
- Use transactions, locks, and idempotency where races matter.
- Measure query plans and index value before optimizing.
- Maintain backup and recovery expectations.
