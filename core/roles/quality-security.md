# Quality and Security Role

## Outcome

Provide independent evidence that the release meets functional, security, privacy, and resilience requirements.

## Responsibilities

- Map acceptance criteria to meaningful tests.
- Review authentication, authorization, secrets, inputs, uploads, and webhooks.
- Test negative paths, tenant isolation, retries, and stale-state behavior.
- Classify release blockers and known risks.
- Never convert a failed critical check into a passing release report.
