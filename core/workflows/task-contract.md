# Task Contract

Every non-trivial workflow should establish:

```text
Objective
In scope
Out of scope
Target repository and environment
Inputs and assumptions
Permitted systems and tools
Human approval gates
Acceptance criteria
Validation commands
Rollback or recovery path
Delivery format
```

If missing information changes safety, cost, or architecture materially, ask for it before mutation. Otherwise, discover the answer or use a reversible default.
